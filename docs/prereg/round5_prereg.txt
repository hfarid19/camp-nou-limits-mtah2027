ADDENDUM 2026-11-13 09:50 CST (wall clock; user request via coordinator: "a model that uses both spatial and temporal attention at

Model (one configuration, fixed now, no tuning): factorised space-time transformer over the degraded tracking at 5 steps / s.
 Tokens = (step, entity) for one frame/ball token + the K = 10 tracked players nearest the (interpolated) ball AT EACH STEP
  (ballc.prepare with K = 10 = the pointer's r5_ptr_ballc inputs with two more players; nearest-first). Per-step choice, not
  window-centre choice: every step's possessor must be among its tokens for the per-step pointer head, and over a 19 s window
  the players near the ball at the centre are often far from it at the edges. Player-token features (10) = the pointer's
  ball-relative, attack-canonical ones (dx, dy, vx, vy, team flag +-1, distance, exp(-d / 2 m), ball-seen flag, speed, rank / K).
  Frame token features = the pointer's 14 frame features xf (interpolated ball position / velocity / acceleration / turn, seen
  flag, time since / until seen, players tracked, speeds, gap) + nn_pff's 194 frame features X (normalised as train_ptr: team-
  symmetric mean / std over the training files, NaN -> 0), exactly as the pointer p20M uses them (like for like). Team swap =
  the pointer's (negate dx, dy, vx, vy, team, xf 0, 1, 10, 11; X permuted / sign-flipped; H <-> A), p = 0.5 in training and
  swap-averaged at inference.
 Tracklets: slot key = slot * 4096 + number of empty -> filled starts of that slot up to the frame (25 fps raw slots); a slot
  reused after a gap is a new tracklet. Undetectable identity swaps inside a continuous tracklet stay merged (no way to see them).
 Blocks (L = 4), each = (a) spatial self-attention across the 11 tokens of the same step (padding masked; no positional
  code: rank is a feature) + FFN, then (b) temporal self-attention: a player token attends only to tokens with the SAME
  tracklet key at other steps of the window (it is among the 10 nearest there), the frame token to all frame tokens of the
  window; padding attends to itself only; + FFN. Relative position in time = rotary encoding (RoPE) on the step index in (b).
  Pre-LayerNorm, D 384, 6 heads, FFN 4D, GELU, dropout 0.1. Parameter count ~14.5M (exact value logged).
 Outputs per step (the frame token is the learned per-step pooling): pointer logits over the 10 player tokens (linear on
  [final player state, input features]) + dead logit (MLP on [frame state, max over player states]) -> softmax -> P(H) =
  sum over home tokens, P(A) over away, P(D) = dead (= the pointer's team_probs); hand-over logit and direct 3-class head on
  the frame token (as the pointer's ho / dir heads).
 Training = train_ptr.py's recipe where it is not architecture-specific: loss team NLL (ls 0.05, 1e-3 floor as ballc) +
  0.5 pointer CE (possessor among the 10 kept; dead -> dead class) + 0.5 hand-over BCE + 0.3 direct-head CE (ls 0.05);

  same total sampled steps as the pointer (6000 x 8 x 1024 = 49.2M): crop 96 steps (19.2 s), batch 64, 8000 iterations;

 Inference: per block and stride-5 phase (as the pointer pipeline), windows of 96 steps every 32 steps; each step's output
  from the window where it is in the central 32 steps (first / last window: their outer parts); swap-averaged; the pointer's
  decoder unchanged (nn_pff_tcn decode_probs with the pointer's P and hand-over probability). CUDA float32, TF32 off.
