# w64: unused 64-game radar variant (dropped)

Weights of `../pipeline_w64.py`: the radar recipe retrained on all 64 PFF World Cup games, which
includes the 16 PFF holdout games already spent on v6. It was neutral at member level (DFL +0.0001 vs the
48-game radar) and was dropped; it is **not part of the submission** and no shipped pipeline loads it.
Kept only so the round-4 64-game results can be re-scored.
